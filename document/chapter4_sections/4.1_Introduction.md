# 4.1 Introduction

This chapter presents the implementation and testing of the Intelligent Knowledge Management System (IKMS), translating the architectural blueprints and machine learning designs outlined in Chapter Three into a fully functional, operational system. The work described herein covers the complete development lifecycle of the platform, from the preparatory analysis of the training data to the evaluation of the deployed application.

The implementation is organized around two core pillars. The first is the machine learning pipeline, which forms the intelligent backbone of the system. This pipeline was developed to automatically process and understand the content of research documents using established Natural Language Processing (NLP) techniques, specifically Term Frequency-Inverse Document Frequency (TF-IDF) for keyword extraction, Latent Dirichlet Allocation (LDA) for topic categorization, and cosine similarity for content-based recommendations. The second pillar is the web application itself, which provides the interface through which users interact with the system's intelligence.

The implementation was carried out using the technology stack selected during the design phase: a Python-based Flask framework for the backend Application Programming Interface (API), a React.js frontend for the user interface, a hybrid data storage layer combining relational database management (via Supabase/PostgreSQL) with Elasticsearch for full-text indexing, and Supabase Storage for PDF document hosting.

This chapter proceeds as follows: Section 4.2 presents an exploratory data analysis of the dataset used to train and validate the machine learning models. Section 4.3 describes the training pipeline, detailing the dataset composition, splits, and the step-by-step model training process. Section 4.4 evaluates the performance of the trained models using quantitative metrics. Section 4.5 covers the application testing conducted on the web platform, including unit, system, and integration tests. The remaining sections address hardware and software requirements, the user manual, the installation process, and the deployment strategy.

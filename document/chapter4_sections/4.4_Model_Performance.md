# 4.4 Model Performance Evaluation

This section evaluates the performance of the machine learning models implemented in the IKMS pipeline, using both quantitative metrics and qualitative assessment. The evaluation was conducted on the held-out test set of 500 documents (20% of the full corpus, as described in Section 4.3.2).

## 4.4.1 Evaluation Metrics

### LDA Topic Model — Topic Coherence Score (C_v)

The primary metric for evaluating the LDA topic model is the **Topic Coherence Score**, specifically the **C_v coherence measure** computed using the **Gensim** library. Topic coherence measures the degree to which the top words in a discovered topic co-occur meaningfully in the original corpus. A higher coherence score indicates that the words within a topic are semantically related and interpretable by a human observer, reflecting a better-quality model.

The C_v score ranges from 0 to 1, where:
- **Score < 0.45:** Topics are largely incoherent and difficult to label.
- **Score 0.45–0.60:** Topics are reasonably coherent with some ambiguity.
- **Score > 0.60:** Topics are highly coherent and clearly interpretable.

To select the optimal number of topics (*k*), the LDA model was trained for values of *k* ranging from 5 to 20, and the coherence score was computed for each. The results guided the final selection of **k = 10**.

### TF-IDF Keyword Extraction — Precision of Top Keywords

Since TF-IDF keyword extraction is an unsupervised process, standard classification metrics (accuracy, F1) do not directly apply. Instead, a **human evaluation protocol** was employed. A subject-matter expert (a faculty member in the health sciences domain) reviewed 50 randomly selected documents and assessed whether the top 10 TF-IDF-generated keywords accurately captured the core topics of the document. Keywords were rated as "relevant" or "not relevant."

### Recommendation Engine — Precision@5

The recommendation system's performance was evaluated using **Precision@5**, which measures the proportion of the top 5 recommended documents that a human assessor judges to be genuinely relevant to the query document. Five research volunteers (graduate students) each evaluated 10 randomly selected documents, rating the relevance of the 5 recommended papers on a binary scale (relevant/not relevant).

## 4.4.2 Model Performance Results Based on Evaluation Metrics

### LDA Topic Coherence Results

The coherence scores for different topic counts (*k*) are summarized in the table below:

| Number of Topics (k) | C_v Coherence Score |
|:---:|:---:|
| 5 | 0.512 |
| 7 | 0.548 |
| **10** | **0.631** |
| 12 | 0.617 |
| 15 | 0.598 |
| 20 | 0.571 |

*Table 4.5: LDA Coherence Scores for Different Topic Counts*

The model achieved its peak coherence at **k = 10** topics with a **C_v score of 0.631**, indicating high topic quality. The decrease in coherence at higher *k* values suggests that beyond 10 topics, the model begins splitting coherent themes into overlapping subtopics, reducing interpretability. The 10-topic model was therefore selected for integration into the IKMS system.

### TF-IDF Keyword Extraction Results

The human evaluation of TF-IDF keyword extraction produced the following results across the 50 evaluated documents:

| Metric | Value |
|---|---|
| Total keywords evaluated (50 docs × 10 keywords) | 500 |
| Keywords rated as "Relevant" | 437 |
| Keywords rated as "Not Relevant" | 63 |
| **Keyword Precision** | **87.4%** |

*Table 4.6: TF-IDF Keyword Extraction Human Evaluation Results*

A precision of **87.4%** demonstrates that the TF-IDF model reliably identifies the most significant and topically relevant terms from research documents. The 12.6% of keywords rated as irrelevant were primarily generic academic terms (e.g., "conclusion," "methodology") that escaped filtering by the custom stopword list. This was addressed by extending the domain-specific stopword list, improving precision on subsequent validation rounds.

### Recommendation Engine Results (Precision@5)

The cosine similarity-based recommendation engine was evaluated by five graduate student volunteers across 10 documents each, resulting in 50 unique query evaluations:

| Metric | Value |
|---|---|
| Total recommendations evaluated (50 queries × 5 results) | 250 |
| Recommendations rated as "Relevant" | 193 |
| Recommendations rated as "Not Relevant" | 57 |
| **Precision@5** | **77.2%** |

*Table 4.7: Recommendation Engine Precision@5 Results*

A **Precision@5 of 77.2%** indicates that, on average, approximately 3.86 out of every 5 recommended papers were considered genuinely relevant by the evaluators. This is a strong result for a content-based system using TF-IDF vectors, particularly given that the ground-truth "relevance" was defined subjectively by different evaluators with varying domain expertise. The system significantly outperforms a random baseline, which would yield a Precision@5 of approximately 20–30% depending on topic distribution.

| Model Component | Metric | Result |

*Table 4.8: Summary of Machine Learning Model Performance*

Overall, the evaluation results confirm that the implemented machine learning pipeline meets the performance expectations established during the design phase. The models demonstrate strong and reliable performance while operating within the computational constraints of an interpretable, classical NLP approach — consistent with the design objective of choosing robust, feasible techniques over complex deep learning alternatives.
